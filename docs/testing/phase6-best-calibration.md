## 现有基线与禁止事项

Fuel 基线在 `apps/api/src/decision/rankFuelBest.ts`，版本 `fuel-best-v1`，price/distance/travelTime/open/availability/freshness/reliability 权重为 0.30/0.10/0.20/0.15/0.10/0.075/0.075。EV 与 Air/Wash 使用各自独立公式，不照搬 Fuel 参数。

保留准入、真实 ETA、价格可比性、缺货、永久关闭、Unknown 与证据过期规则。无论转化是否上升，都不得用更高点击率为失效价格、错误营业或虚构 EV availability 放行。现有单元、解释一致性、排序不变性和 HTTP/PostGIS 回归继续作为硬门槛。

本轮本地指标没有候选特征快照、排名曝光位置、实验分组或独立参与者统计，因此不适合作为训练集或因果效果证据。公开仓库的示例和测试数据不能当作用户导航行为。单击/系统接收链接也不是抵达或解决问题。

## 执行顺序

1. 先关闭 Phase 5 发布前置条件，批准采集目的、最小字段、同意、处理者及保留期限。禁止直接上传目前本地诊断记录、原始搜索、起点/路径或稳定设备 ID。
2. 预注册一个明确假设及单服务/区域范围，例如在证据门槛不变时比较旅行时间与价格权重。正式数据采集前填写下表，不事后选择最有利窗口/分组。
3. 冻结 baseline 版本、指标定义、候选版本与最大变更范围。保留 request → exposure → navigation click / handoff 的完整关联，区分重试和用户，记录实际应用的排序及降级；未展示候选不能当作被用户拒绝。
4. 在授权样本上先做只读离线重排：相同候选和字段证据；记录 top-1/top-3 变更、硬门槛不变和排名理由变化。历史被点击项命中率只能作描述，需报告位置偏差、旧策略选择偏差和缺失证据，不能据此宣布新策略更好。
5. 样本满足预注册标准后才考虑获批的对照实验。记录分组比例、分配单位、串组/重复参与影响，按服务、国家、城市/郊区/高速及能力限制分层；不把来源更新或延迟差异误当权重效果。
6. 以预注册的导航点击指标及时间/数据风险护栏共同评估，报告区间和缺失、取消、截断、退出未知数。未达样本要求、效果区间不明确或单区域退化：保留基线、继续有限 Beta，不自动扩区。
7. 人工审查批准才发布新公式版本，逐项 commit/push 并保留旧版本。灰度策略、监控负责人和回滚触发填写后，在所选平台真实演练。回滚恢复旧权重版本，不删除原始审查记录，不回滚必要安全修复。

## 设计验收与剩余工作

- 合成样本、空样本、没有对照/位置记录：只允许验证程序，不调权、不声称提升。
- 结果中存在未知关键字段：保留降级，候选策略不能恢复被禁的比较。
- 点击提高但错误导航/陈旧风险上升：不发布，调查原因。
- 全局改善但西班牙或某服务退化：按分层护栏处理，不用全局均值掩盖。
- 真实采集、实验实施、校准结果、平台灰度/回滚与批准仍未完成；`P6-BEST-01` 保持未勾选。
