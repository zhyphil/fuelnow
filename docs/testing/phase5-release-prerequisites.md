## 工程侧仍须完成，不转嫁为用户输入

1. 正式数据链路：已有 Fuel 适配器、导入基础设施与 API SQL 读取，但尚未走通持续采集 → canonical 数据投影 → 四服务搜索。EV/OSM 正式接入存在缺口。当前本地业务库空；测试 fixtures 与临时负载库不是生产数据。须补齐必要来源实现、事务/失败恢复、调度与真实数据验证，再关闭 QA-10 / REL-04。
2. 隐私审计：依据实际构建确认原生权限最小化、前台定位、缓存、日志、地图/路线处理方和设备 SDK 行为；代码侧限制不等于部署侧全部通过。
3. 许可复核：关闭现有 OSM ODbL 合并/提供义务与 MITECO 条款解释风险；Reve 未获授权继续禁用，法国动态数据保留既定能力边界。不能因发布压力开启无许可来源。
4. 运行保障：质量审计命令已有，但尚非线上告警；仍需错误/性能/同步监控、通知路由、失败演练、备份与回滚验证。
5. Beta 验收：三语政策/条款、来源展示、发布说明、真实反馈渠道和四服务原生流程回归，尤其定位、弱网、地图、导航、读屏/大字体验。
