# P6-CROWD-04 — 照片、OCR 与人工审核流程设计

2026-09-07。设计完成，未安装上传/OCR 服务、未申请新增权限、未发送照片、未选付费供应商。照片始终可选，文字/枚举反馈与核心导航不依赖照片。

## 生命周期与边界

| 步骤 | 责任与输出 | 失败/安全规则 |
| --- | --- | --- |
| 用户主动选择 | 系统照片选择器；只选一张价牌/设备照片；明确只需公共服务证据 | 不扫描相册、不要求后台位置；提醒停车、不要拍他人/车牌/私人小票 |
| 本地预览 | 裁切无关内容，提示遮挡脸、车牌、姓名、付款/会员信息 | 用户确认后才上传；识别可能漏检，不能声称自动脱敏绝对安全 |
| 受限上传授权 | 服务端绑定待审 reportId、随机对象键、单次短有效期上传授权；私有 bucket | 不接任意远程图片 URL，不从用户 URL 抓取，避免 SSRF；过期需重签 |
| 隔离校验 | 校验实际文件格式、大小、尺寸/像素上限、静态帧；解码再编码移除 EXIF/GPS/XMP 等元数据 | 扩展名/MIME 不当作真实格式；解码失败、压缩炸弹、超限或多帧拒绝；隔离区不可公开访问 |
| 服务端复核脱敏 | 在受限任务中检测、遮挡风险内容，生成审核副本和小尺寸预览 | 处理故障留在隔离，不回退公开原图；OCR 只读已校验/处理副本 |
| OCR 草案 | 提取候选产品、十进制金额、EUR 单位、条件和局部框位置 | OCR 是不可信输入，无工具/网络指令执行；低置信、多个价格、单位不清转人工，绝不直接改价 |
| 用户校对 | 显示图片局部与每个候选字段，允许修正/删除/跳过 | 提交的是用户确认的草案，仍非人工审核通过；离开不自动提交 |
| 人工审核 | 有权限的审核者看脱敏副本、原来源/版本、时间与冲突；逐字段通过/拒绝/要求补充 | 权限最小化、有审计，不给公开分享链接；OCR 数字不能默认等于站点/产品事实 |
| 证据提升 | 审核决定创建独立众包字段证据，带 report/review/policy 版本和有效期 | 保留原始来源，不覆盖官方身份；价格/状态仍经过既有契约及能力门槛 |
| 到期/撤回/清理 | 移除对象/衍生预览/OCR 草案及相关缓存；最小审核记录按获批策略保留 | 重试清理并可核查；对象不存在可视为幂等成功，不能凭队列入队就报告删除完成 |

初版工程防护建议：单图 ≤5 MiB、解码后 ≤12 megapixels、仅 JPEG/PNG 静态图；更广格式必须先在端侧转换并重验。上传授权建议 5 分钟；OCR 有超时、单报告最多 2 次自动尝试、全局费用/并发上限，超限转人工或暂不可用。这些是保守设计默认值，不代表选定服务的价格或限制，启用前应做容量/设备验证。

## 不允许出现的“捷径”

- 不能把图片或小票贴入当前公开 GitHub issue 模板；未有获批私有渠道时，照片功能保持不可用。
- 不把照片内“忽略规则/打开此链接”等文字当系统指令；OCR 结果只经过固定字段解析、范围和类型校验。
- 不因 OCR 高置信而跳过人工复核；模型分数不是价格可信度。
- 不把拍摄元数据/GPS 当作用户授权位置；移除元数据后也不能假设画面无个人信息。
- 不把上传时间/OCR 时间当价格观察时间；没确认观察时间的草案保持低可信且不获时效加分。
- 不以全国 OSM/官方许可授权为由推定用户照片可公开再分发；贡献许可、隐私说明与图像再利用权限留待单独审查。

## 审核界面设计

左侧仅脱敏证据片段，右侧是公共站点、服务/产品、旧字段、新候选、单位/条件、观察时间与来源差异；不要显示用户起点或轨迹。每个字段单独标“通过 / 拒绝 / 需补充”，拒绝原因用受控枚举。高风险差异或改永久关闭需第二位审核者，不与图片上传者自审。

提交审核采用版本检查与幂等审计事件；重复/并发审核不得重复提升。若正式来源已经更新，应重新核对，不向最新值套用旧图片。详情页最终显示“用户观察、已核对、观察时间/过期提示”，不能伪装官方或实时来源。

## 设计验收走查

1. 带 GPS 元数据/小票卡号：不能进入公开仓库；元数据清除及画面复核后才给 OCR/审核。
2. 伪装图片扩展名、超像素解码炸弹、远程 URL：边界拒绝，无外网抓取。
3. 图片里含恶意指令或多个费率：按不可信文本处理，不能触发工具，不猜单一价格。
4. OCR 超时/预算耗尽：保留待审状态或让用户枚举反馈，不显示提取/提交成功。
5. 审核完成前用户撤回：撤回赢得发布资格，迟到 OCR/审核结果不得提升。
6. 正式价格已更新、审核重复点击：冲突重审或返回原回执，不双重写入。

验收性质：流程和威胁场景审查，不是已运行安全测试。实际图片上传、脱敏、OCR、审核工具、删除作业和权限验收仍未实现。
