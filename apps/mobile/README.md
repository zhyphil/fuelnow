# `@fuel-now/mobile`

Expo React Native client workspace for the iOS and Android V1 application.

The mobile application consumes versioned contracts from `@fuel-now/contracts`. It must not contain source-provider credentials, source import logic or direct calls to government/OSM/Reve data endpoints.

The Expo project itself is initialized in Phase 4; this Phase 2 scaffold reserves the stable workspace boundary without selecting UI implementation details early.
